# Search B4 Purchase Website

Static website for Search B4 Purchase, a product research and comparison app by Core CNC Solutions Inc.

## GitHub Pages

This repository is ready for GitHub Pages. In **Settings → Pages**, select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then save.

## Domain

The intended production domain is `searchb4purchase.com`. Connect the custom domain only after the GitHub Pages preview has been checked.

## Important pre-launch tasks

- Confirm the public support email address.
- Have the Privacy Policy and Terms reviewed before the app launches.
- Replace “Coming Soon” buttons with App Store and Google Play links when available.
- Update preliminary pricing if it changes.
